# MAX для Windows 1.0.2

Версия 1.0.2 сохраняет все исправления 1.0.1 и добавляет новую иконку,
улучшения установщика и подготовку к финальному выпуску.

> **Статус подписи.** Сборка подписана самоподписанным сертификатом издателя:
> Authenticode-подпись и метка времени присутствуют, но Windows не считает
> издателя доверенным. По требованиям выпуска сборка опубликована как тестовая.
> Для финального релиза нужен сертификат доверенного центра сертификации.

## Что нового

### Иконка

- Новая цветная иконка MAX установлена в `Max.exe`, `MaxSetup.exe`, ярлыки,
  заголовок установщика, `ico/`, `assets/`, `docs/icon.png` и архив исходников.

### Установщик и UAC

- Исправлено обновление 1.0.0 в папке с посторонними файлами: существующая
  установка определяется по `ProductName`/`CompanyName` и обновляется на месте,
  а не создаёт подпапку `MAX` в silent-режиме.
- При отмене запроса UAC установка и удаление больше не завершаются молча:
  показывается понятный результат, изменения не вносятся, повторный запуск
  возможен.
- Выбор сохранения или удаления профиля WebView2 передаётся при повторном
  запуске удаления с повышенными правами вместе с путём к профилю пользователя,
  начавшего удаление.
- `Max.exe` подписывается до упаковки в установщик, затем подписывается
  `MaxSetup.exe`. Деинсталлятор сохраняет подпись установщика.

### Диагностика

- Действия горячих клавиш записываются в журнал (`reload`, `back`, `forward`,
  `zoomIn`, `zoomOut`, `zoomReset`, `fullscreen`, `exitFullscreen`).
- `SIGNATURE-STATUS.txt` фиксирует статус `Get-AuthenticodeSignature`,
  наличие метки времени и признак доверия Windows для `Max.exe` и
  `MaxSetup.exe`.
- В `build.ps1` добавлен режим `-RequireTrustedSignature`: выпуск
  останавливается, если подпись не возвращает `Valid`.

### Сохранено из 1.0.1

- Манифест установленных файлов и обновление только файлов приложения.
- Откат при ошибке замены файлов.
- Сохранение посторонних файлов и удаление папки только если она пуста.
- Защита путей с учётом символических ссылок и junction-ссылок.
- Закрытие только установленного `Max.exe`; сторонний процесс `Max` не
  затрагивается.
- Сохранение профиля WebView2 по умолчанию; удаление только по явному флажку.
- Явный список HTTPS-источников и политика внешних ссылок.
- Разрешения камеры, микрофона, уведомлений и буфера обмена только для
  `https://web.max.ru`.
- Проверка Authenticode-подписи встроенного загрузчика WebView2.
- Очистка журналов от полных URL, query-параметров и локальных путей.

## Проверка

Протокол приёмки: [docs/ACCEPTANCE.md](https://github.com/Hyndex322/max-web-desktop/blob/main/docs/ACCEPTANCE.md).

Автоматизированные проверки установки под обычным пользователем, обновления
с 1.0.0, отката, удаления, сохранения посторонних файлов, junction-ссылок,
подписи WebView2, политики навигации и горячих клавиш пройдены на Windows 10
21H2 x64. Интерактивные сценарии входа, камеры/микрофона, скачивания файлов,
UAC стандартного пользователя и архитектуры x86/ARM64 отмечены в протоколе
как непроверенные или требующие ручной проверки.

> принадлежат правообладателям.

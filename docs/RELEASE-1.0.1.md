# MAX для Windows 1.0.1

Обновление 1.0.1 посвящено безопасной установке и удалению, политике WebView2
и подготовке релиза к распространению.

## Исправления и доработки

### Установка, обновление и удаление

- Установка по умолчанию в `%LOCALAPPDATA%\Programs\MAX` — без обязательных
  прав администратора.
- Если в выбранной папке уже есть посторонние файлы, установщик предлагает
  подпапку `MAX` или другой путь.
- Появился `.max-install-manifest` — список установленных файлов. Обновление и
  удаление работают только с этим списком.
- При обновлении заменяются только файлы приложения. Перед заменой создаётся
  резервная копия; при ошибке предыдущая версия восстанавливается.
- Посторонние файлы в папке установки сохраняются; папка удаляется только если
  осталась пустой.
- Проверяются границы папки установки с учётом символических ссылок и точек
  соединения. Фоновая очистка после выхода деинсталлятора использует те же
  проверки и манифест.
- Перед заменой файлов закрывается только `Max.exe` из папки установки.
  Сторонний процесс с именем `Max` не затрагивается.
- Профиль WebView2 при удалении **сохраняется по умолчанию**. Для удаления
  входа нужно явно поставить флажок. Выбор передаётся при перезапуске удаления
  с повышенными правами вместе с путём к профилю исходного пользователя.

### WebView2: навигация и разрешения

- В основном окне разрешены только `https://web.max.ru`, `https://max.ru` и
  `https://www.max.ru`. Проверка выполняется при переходах, редиректах и
  запросах нового окна.
- Внешние HTTP(S)-ссылки открываются в системном браузере только по явному
  действию пользователя. Автоматические переходы и редиректы блокируются.
- Для специальных схем разрешены только `mailto:` и `tel:`; `file:`,
  `javascript:`, `data:`, `vbscript:` и `ms-*` блокируются.
- Разрешения привязаны к точному источнику `https://web.max.ru` и типу запроса.
  Для камеры и микрофона показывается стандартный диалог согласия; остальные
  разрешения, кроме уведомлений и чтения буфера обмена, запрещены.
- Инструменты разработчика, автосохранение паролей и доступ веб-страницы к
  объектам приложения остаются отключены.

### Горячие клавиши и окно

- Горячие клавиши обрабатываются при фокусе внутри WebView2 через
  инжектированный обработчик и `WebMessageReceived`.
- `F11` включает полноэкранный режим, `Esc` выходит из него.
- Сохранение размеров и положения окна сохранено.

### WebView2 Runtime и релиз

- Встроенный загрузчик WebView2 распаковывается в отдельную временную папку с
  ограниченным ACL и проверяется через `WinVerifyTrust`; издатель должен быть
  `Microsoft Corporation`. Изменённый загрузчик не запускается.
- При тайм-ауте, отсутствии сети или ошибке установки Runtime показывается
  понятная причина и предложение повторить; можно продолжить без Runtime.
- `Max.exe` и `MaxSetup.exe` подписываются Authenticode с меткой времени.
  Деинсталлятор — копия подписанного установщика, поэтому сохраняет подпись.
- `SHA256.txt` формируется после подписания.
- Добавлены архив исходников и протокол приёмки.

### Журналы

- Из журналов убраны полные URL, query-параметры и полные локальные пути.
- Для диагностики остаются тип события, код ошибки, домен и имя файла.

## Подпись

Релиз подписан самоподписанным сертификатом издателя
`CN=MAX Messenger (unofficial build)`. Подпись и метка времени действительны,
но сертификат не входит в доверенные корневые сертификаты Windows, поэтому
SmartScreen может показать предупреждение. Для публичного релиза без
предупреждений нужен сертификат доверенного ЦС.

## Проверка

Протокол приёмки: [docs/ACCEPTANCE.md](https://github.com/Hyndex322/max-web-desktop/blob/main/docs/ACCEPTANCE.md).

Автоматизированные проверки установки, обновления, отката, удаления,
сохранения посторонних файлов, junction-ссылок, подписи WebView2 и политики
навигации пройдены на Windows 10 21H2 x64. Интерактивные сценарии входа,
камеры/микрофона, скачивания файлов, UAC и архитектуры x86/ARM64 требуют
отдельной ручной проверки.

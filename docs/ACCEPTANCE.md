### Детали ключевых проверок

**Обновление и откат.** При обновлении файл `Max.exe` был открыт с
`FileShare.None`, замена завершилась ошибкой `0x80070020`. Установщик
восстановил предыдущий файл, `Get-FileHash` до и после совпал, приложение
продолжило запускаться.

**Точка соединения.** Внутри папки установки создавалась junction-ссылка на
внешнюю папку с файлом `secret.txt`. После удаления внешний файл остался,
ссылка не была развёрнута, а папка установки сохранилась, потому что не была
пустой.

**Сторонний процесс `Max`.** Копия PowerShell была запущена как `Max.exe` из
другой папки. Установщик закрыл только `Max.exe` из папки установки;
сторонний процесс остался жив.

**Горячие клавиши.** Окно приложения было активировано, после `F11` стиль окна
сменился с `0x16CF0000` на `0x17010000`, окно заняло весь экран
`1600x900`. После `Esc` стиль и размеры восстановились до `0x16CF0000`
и `1100x800`.

## Подпись и контрольная сумма

Сборка 1.0.1 подписана самоподписанным сертификатом издателя
`CN=MAX Messenger (unofficial build), O=MAX Messenger, C=RU`.
`Get-AuthenticodeSignature` показывает `Status = UnknownError`, потому что
корневой сертификат не входит в доверенные. При этом подпись и метка времени
присутствуют; для релиза без предупреждений SmartScreen нужен сертификат
доверенного центра сертификации.

Контрольная сумма итогового установщика:

```
36F269312F7BA271E6D6AC42EC9BA05DF81C24933A199E992EFECDD1EE7B8139 *MaxSetup.exe
```

Она также публикуется в `dist/SHA256.txt` и в описании GitHub-релиза. Проверка:

```powershell
Get-FileHash .\MaxSetup.exe -Algorithm SHA256
Get-AuthenticodeSignature .\MaxSetup.exe | Format-List Status, SignerCertificate, TimeStamperCertificate
```

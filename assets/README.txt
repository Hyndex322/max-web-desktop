MAX для Windows (web.max.ru)
============================

Неофициальное приложение для сайта web.max.ru.
Проект не связан с MAX/VK; название и логотип принадлежат правообладателям.

УСТАНОВКА
---------
1. Запустите MaxSetup.exe (двойным щелчком).
2. Выберите диск в списке или укажите любую папку кнопкой «Обзор...».
   По умолчанию программа устанавливается в C:\Max.
3. Нажмите «Установить».
   Если система запросит права администратора — разрешите установку.
   Установщик сам поставит компонент Microsoft Edge WebView2, если его нет.
4. На рабочем столе появится ярлык MAX. Запускайте программу с него.

ПЕРВЫЙ ЗАПУСК
-------------
Откроется страница web.max.ru. Войдите в аккаунт удобным способом
(QR-код или номер телефона). После входа сессия сохраняется автоматически:
при следующих запусках логин вводить не нужно.

ОКНО ПРОГРАММЫ
--------------
Приложение открывает только сайт MAX: нет адресной строки, вкладок и прочего
интерфейса браузера.

Горячие клавиши:
  F5 или Ctrl+R      — обновить страницу
  F11                — полноэкранный режим (Esc — выйти)
  Alt+Влево / Вправо — назад / вперёд
  Ctrl+ + / Ctrl+ -  — увеличить / уменьшить масштаб
  Ctrl+0             — обычный масштаб

УДАЛЕНИЕ
--------
Способ 1: Параметры Windows → Приложения → MAX Messenger → Удалить.
Способ 2: запустите Uninstall.exe в папке установки.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Сессия и настройки: %LOCALAPPDATA%\MAX Messenger
Журнал ошибок:       %LOCALAPPDATA%\MAX Messenger\logs\app.log
Журнал установки:    %TEMP%\MAX-Setup.log

При удалении программы можно сохранить или удалить данные входа
(соответствующий флажок в окне удаления).
